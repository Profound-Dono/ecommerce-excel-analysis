# Data Dictionary

## Sales Dataset

| Field         | Description                                   | Data Type |
| ------------- | --------------------------------------------- | --------- |
| Order ID      | Unique identifier for each order              | Text/ID   |
| Order Date    | Date the order was placed                     | Date      |
| Customer ID   | Unique identifier for the customer            | Text/ID   |
| Product ID    | Unique identifier for the product             | Text/ID   |
| Product       | Name of the product purchased                 | Text      |
| Category      | Product category                              | Text      |
| Sales Channel | Channel through which the order was generated | Text      |
| Quantity      | Number of units purchased                     | Integer   |
| Unit Price    | Price per unit                                | Decimal   |
| Revenue       | Total revenue generated by the order          | Decimal   |

## Calculated Metrics

| Metric              | Definition                                                    |
| ------------------- | ------------------------------------------------------------- |
| Revenue             | Total sales revenue                                           |
| Orders              | Number of unique orders                                       |
| Customers           | Number of unique customers                                    |
| Average Order Value | Total revenue divided by number of orders                     |
| MoM Growth          | Percentage change in revenue compared with the previous month |

## Data Quality Checks

The dataset was reviewed for:

* Missing values
* Duplicate records
* Invalid dates
* Inconsistent category values
* Suspicious prices
* Suspicious quantities
* Impossible values
* Incorrect data types
